# Лапки Вышки — сайт-проект

Готовый статический сайт для публикации на GitHub Pages.

## Что внутри
- адаптивный сайт с разделами: карта, о проекте, волонтёрство, лучший друг, поездки, ИнстаЛапки, образовательное;
- интерактивная карта с шестью приютами, метками-лапками, карточками и фильтрами;
- календарь с демонстрационными выездами 30 ноября и 15 декабря 2026 года;
- интерактивные аватары животных, включая предоставленную собаку, таксу, чёрного пса и котят;
- лента в стиле сообщества ВКонтакте;
- карточки и модальные окна образовательных статей;
- деликатный след лапок за курсором.

## Запуск
Открой `index.html` в браузере или загрузи всю папку в GitHub-репозиторий.

## Публикация на GitHub Pages
1. Создай публичный репозиторий, например `lapki-vyshki`.
2. Загрузи **все файлы и папку assets** из этой папки в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`, ветку `main`, папку `/ (root)`, нажми Save.
5. Через несколько минут сайт будет доступен по адресу `https://ТВОЙ-ЛОГИН.github.io/lapki-vyshki/`.

## Яндекс.Карты
Для подложки Яндекс.Карт нужен собственный ключ JavaScript API:
1. Получи ключ в кабинете разработчика Яндекса для JavaScript API.
2. Открой `config.js` и замени `YOUR_YANDEX_MAPS_API_KEY` на свой ключ.
3. Добавь домен GitHub Pages в разрешённые домены ключа.
4. После этого сайт автоматически использует Яндекс.Карты. Пока ключ не добавлен, работает OpenStreetMap как резервная подложка.

## Что заменить перед запуском
- В `app.js` проверь координаты приютов: сейчас они приблизительные, адреса из вашего списка сохранены.
- Уточни актуальные часы, контакты и списки необходимых вещей непосредственно у приютов.
- В календаре `trips` отредактируй описания поездок; время и место сейчас указаны как уточняемые.
- Замени демонстрационные имена и истории животных на реальные анкеты, фото и ссылки. Первая фотография в ленте — фото собаки с цифрой 1; в аватаре Рекса — вторая загруженная фотография.
- Добавь реальные ссылки Telegram и ВКонтакте команды в блоке «Поехали вместе!».

## Важно
Названия, адреса, контакты и списки нужд отображаются на основе переданного вами текста. Координаты точек демонстрационные и не должны использоваться для навигации до проверки. Имена животных и анонсы поездок — макетные.
